# 设计审查基线与实施记录

日期：2026-10-16。产品：剧本杀线索整理 APP（迹册）；核心设备：iPad mini 7。

## 审查范围与方法

Vue 3 + TypeScript + Ionic Vue / Capacitor；App.vue 通过本地 view 状态组织主要页面，专用组件承载人物工作台、关系图、时间线、对照与浮层。全局样式由 style.css、reading.css 和 design-tokens.css 提供，线索库另外使用 styles/clue-library.css；组件还拥有 scoped 样式。

Vue 与服务代码通过 CodeGraph 定向阅读，CSS 是 CodeGraph 不收录的类型，仅定向读取已知样式文件。ui-ux-pro-max 的设计系统检索结果两次偏向展示网站，未采用其营销页面结构与英文字体；触控尺寸与间隔查询命中。Vue 专项两次没有匹配，实施使用技能通用规范和项目现有写法。

以下区分源码可确认的布局/样式问题与需要实机观察的行为风险。此次只实施线索库试点，审查其他页面不等于修改其他页面。

## 根因

1. 历史CSS、后加载的reading.css与组件scoped规则叠加，同一意图的控件在不同页面拥有不同尺度。
2. 已有token，但仍存在独立颜色、字号、圆角与局部覆盖。旧文档没有及时记录哪些页面已经接入。
3. 触控目标与信息密度没有同时规划：保证每个按钮44px之后仍逐项纵向堆放，浪费了可并排使用的空间。
4. 状态有时只用颜色区分；筛选等表单缺少持久可见的上下文。

## 视觉方向与实现规则

- **色彩**：保留白色阅读表面、灰蓝画布和深灰文字，主操作使用灰蓝实底；警告、失败与收藏同时给出文字、图标或勾选，不用色彩表达案件结论。
- **排版**：系统中文字体，页面26px、资料标题16px、列表摘要15px、辅助12px。标题/元数据可同排，长标题最多两行；原始正文在详情完整阅读。
- **布局**：页面边距16–24px，4/8px间距节奏。列表是一张连续资料表面；图片与文本分栏，按内容宽度换行，窄屏保持原阅读顺序。
- **组件**：常用操作区44px；图片不裁边，主次操作明确。筛选字段始终有名称，已选状态可识别，支持明确结束操作。
- **动效**：复用120ms按压、180ms面板规范，只做颜色/边界等轻量反馈；减弱动效使用现有关闭规则，不添加动画依赖。
- **实施边界**：此次产品源码仅涉及 App.vue 的线索库模板和 styles/clue-library.css；不引入数据结构、API或业务能力。
