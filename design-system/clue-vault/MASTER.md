# 线索研究工作空间 · 设计规范

版本：2026-10-16 · 线索库阅读密度与筛选交互试点

## 目的与实施边界

面向 iPad mini 7 的剧本杀线索整理工具。界面服务于「录入 → 浏览与核对 → 关联 → 整理」：先让原始资料可读、操作可预期，再用克制的灰蓝强调建立识别。以排版、对齐和适当密度体现品质，不用主题贴图、渐变、发光或 3D 装饰。

现有工程中，线索库、人物工作台、记录对照、整理总览、设置和部分浮层已使用 `--cv-*`；关系与时间线仍存在局部样式覆盖，人物列表和整理板还有尺度缺口。此次实施只细化**线索库**，通过一页确认阅读密度与筛选交互，再决定下一批接入。保留 Vue / TypeScript / Ionic Vue / Capacitor 架构、已有数据结构与 API。

`src/design-tokens.css` 是实现中的 `--cv-*` 值来源；本文件记录使用语义。线索库专属规则见 [pages/clues.md](pages/clues.md)，审查依据见 [AUDIT.md](AUDIT.md)。

## 方向如何落到界面

- **阅读优先**：标题、摘要、来源元数据分层；图片保留完整文档，方便认出资料。关键文字不再使用极浅灰。
- **稳定操作区**：浏览控制固定在内容上方，列表在其内部滚动；方向切换由可用宽度决定换行，不另造一套视觉语言。
- **克制容器**：列表是一张连续表面，通过分隔与间距组织条目；网格仍可用卡片。无需为每一段信息再套一层卡片。
- **明确语义**：主操作用实底强调，筛选用可选状态，元数据用安静文字；相同外观不能同时暗示“可点击”和“只读”。
- **触控先行**：常用控件有 44px 操作区；功能不依赖 hover。图标按钮保留可访问名称与清晰选中状态。

## 1. Color Tokens

| Token | 值 | 用途 |
|---|---|---|
| `--cv-canvas` | `#F5F7F9` | 工作区底色 |
| `--cv-surface` | `#FFFFFF` | 主要阅读表面 |
| `--cv-surface-subtle` | `#EEF2F5` | 次级分组与禁用底色 |
| `--cv-image` | `#E8EDF1` | 图片承载面 |
| `--cv-ink` | `#24313D` | 标题、主要内容 |
| `--cv-secondary` | `#526574` | 摘要、次级操作 |
| `--cv-muted` | `#5E6E7C` | 日期、来源等辅助内容 |
| `--cv-accent` | `#466879` | 主要操作、选中 |
| `--cv-accent-strong` | `#344F5E` | 强调操作按压态 |
| `--cv-accent-soft` | `#E8F0F4` | 柔和选中表面 |
| `--cv-border` | `#DDE5EB` | 内容分隔与容器边界 |
| `--cv-border-strong` | `#8498A6` | 需要明确识别的控件边界 |
| `--cv-focus` | `#315F78` | 键盘焦点 |

| `--cv-danger` | `#A43F3A` | 删除与危险操作 |
| `--cv-success` | `#356653` | 完成状态 |

内容文字使用 ink / secondary / muted，不用降低整个控件 opacity 来表达次要。状态同时提供文字或图标，不能仅靠颜色。普通边框用于结构，交互边界需要时使用 border-strong。

## 2. Typography Scale

使用原生系统字体：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Noto Sans SC', sans-serif`；中文随系统字体回退，不加载网络字体。

| 层级 | 字号 | 建议字重 / 行高 |
|---|---:|---|
| 页面标题 | 26px | 650 / 1.5 |
| 条目标题 | 16px | 600 / 1.5 |
| 正文 | 15px | 400–500 / 1.7 |
| 摘要 | 14px | 400 / 1.7 |
| 输入文字 | 16px | 400 / 1.5 |
| 辅助、标签、元数据 | 12px | 400–550 / 1.5 |

中文不使用大幅负字距或强制英文大小写。标题最多两行，摘要按场景截断；原文详情允许完整阅读。时间和编号使用等宽数字特性，长名称用正常换行或明确截断，不能挤坏操作。

## 3. Spacing System

基础级：**4 / 8 / 12 / 16 / 24 / 32px**。4px 用于紧密元素，8px 用于图标与文字，12–16px 用于组件内部，24px 用于内容段落，32px 只用于较大区域。可交互控件之间尽量保留 8px 间隔。

## 4. Border Radius System

标签 **6px**、按钮/输入/分段控件 **10px**、面板 **14px**。编号与元数据不必都做胶囊。不要为了统一而给所有内容增加外框，也不要用大圆角代替布局层级。

## 5. Shadow / Elevation System

卡片、列表默认**无阴影**；靠表面与分隔组织信息。仅菜单、弹层使用轻阴影，例如 `0 8px 24px rgba(36,49,61,.10)`，并有真实遮挡关系。保留原业务弹窗的层级组织，本轮不更改全局 z-index。

## 6. Iconography

复用 `UiIcon` 的线性 SVG，常用图标 **20px**，保持描边与光学大小一致。图标按钮操作盒为 **44×44px**；图形无需填满热区。图标不充当装饰性杂项，也不使用 emoji 替代功能图标。只显示图标时添加 `aria-label` / `title`；选中态不能只依赖提示文字。

## 7. Component States

| 状态 | 视觉与交互 |
|---|---|
| 默认 | 白色或透明表面，清晰文字与边界 |
| 按压 | 强调/柔和表面变化，点击响应即时 |
| 选中 | accent-soft 与 accent，必要时加勾选或 `aria-pressed` |
| 焦点 | 2px focus 外框，2px 外偏移，不移除键盘提示 |
| 禁用 | 明确不可操作，保留可理解文字，不与加载混淆 |
| 加载 | 复用已有状态与文案，稳定布局，避免按钮宽度跳动 |
| 失败 | 邻近操作给出原因与已有重试入口，warning/danger 与文字并用 |
| 空状态 | 说明当前范围无结果，保留清除筛选或录入入口 |

输入框、普通按钮统一 **44px** 高；筛选标签的操作区同样满足触控尺寸。只读标签可紧凑，不能与筛选按钮采用完全相同语义。

## 8. Motion Guidelines

按压反馈 **120ms**，面板显隐 **180ms**；只使用 opacity / color / border-color 等轻量变化。展开内容优先稳定布局，避免持续动画、弹跳、缩放整个页面与装饰性位移。不引入动画依赖。`prefers-reduced-motion: reduce` 时去掉非必要过渡。

## 9. Layout Grid

页面边距使用 16–24px，主要间隔 16px。主要阅读区使用 `minmax(0,1fr)` / `min-width:0`，确保长中文不会推出画布。列表缩略图与文本形成两栏；文本不额外拆成嵌套卡片。工具栏按“查找范围 → 浏览方式 → 批量操作”排列，主操作有唯一重心。

应用外壳、工具区和底部导航稳定；内容区用 `flex:1; min-height:0`，将滚动限制在用户实际浏览的区域。安全区只计算一次，不通过留出大量空白规避 Home 指示条。

## 10. Responsive Rules

根据可用宽度与内容空间调整，沿用当前工程断点；不引入另一套路由或设备判断。iPad 横竖屏保持内容顺序、语义和组件风格一致；窄宽时控制区自然换行。网格随宽度改变列数，列表持续显示完整文档缩略图与正文。

在桌面/键盘环境保留 Tab、Enter/Space、焦点反馈；移动触控不依赖 hover。安全区、缩放与局部手势保持原有负责组件的边界。本轮不改图片查看器及图谱手势。
