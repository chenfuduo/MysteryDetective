# iPad mini 7 实机验收

本清单记录操作和预期，不代表已完成实机验收。本轮没有连接或部署 iPad。

## 1. 时间完整性

- 用含“6月16日晚10点27分进入，10点29分离开”的 OCR 整理。
  - 预期：两个独立事件保留到分钟；晚间换算为22:27/22:29，不丢时分。
- 用一张同时包含医院监控与城市监控、后半段3:10/3:24/3:26/3:45/4:42的 OCR 整理。
  - 预期：第二轮核对覆盖后半段；未覆盖项明确出现在待复核摘要，不能宣称全部核完。
- 分别录入仅日期、仅小时、具体分钟、含“约/左右”的时间。
  - 预期：保留原精度和约时，不补年份、分钟或未写出的事件。
- 点击任一建议或已确认事件的出处。
  - 预期：打开对应原照片，并显示原文摘录；多出处逐一可查看。

## 2. 增量、隔离与恢复

- 整理两张照片后，再点整理。
  - 预期：没有改动时不再调用模型，已有结果保留。
- 新增第三张；再修改第二张 OCR。
  - 预期：分别仅整理新增或修改的文字，不重发未改动线索。
- 中断批量处理后重试。
  - 预期：已完成条目从检查点恢复，只继续未完成条目。
- 两个剧本使用同名人物、相同编号与相同 OCR。
  - 预期：建议、出处、视图位置和撤销严格属于当前剧本。
- 两张照片记载同一明确事件，另有一张记载不同时间。
  - 预期：精确相同事件保留多个出处；不同时间分别保留，不猜测哪份为真。

## 3. 确认与撤销

- 在事件编辑中手动合并同一时间、不同表述的记录，再撤销。
  - 预期：合并保留全部出处和人物；撤销恢复两条原记录；不同时间不出现在合并选项中。

- 跨分类勾选人物、关系、事件后批量录入。
  - 预期：确认所选项；缺标题项目保留；没有二次补全年份或分钟的要求。
- 批量忽略或清除全部，然后撤销。
  - 预期：恢复上次建议；没有重复记录，也不恢复到其他剧本。
- 新增/删除关系、编辑/删除事件后撤销。
  - 预期：恢复原ID、出处及内容；后续内容已变更时阻止覆盖。
- 拖动人物后撤销；离开关系图再返回。
  - 预期：移动可撤销，返回保留该剧本的缩放与位置。

## 4. 讨论时查阅

- 点人物进入工作台。
  - 预期：在同一面板查看其事件、线索、手动关系；可进入另一人物或直接查看原文。
- 从工作台点事件定位时间线。
  - 预期：横屏居中选中，竖屏滚动至对应项，不出现被筛选隐藏的事件。
- 在时间线缩放/筛选、打开关闭详情，再横竖屏切换。
  - 预期：筛选不改变时间比例，保留视图，显示全部可找回所有事件。
- 原图放大后拖到四个边缘，旋转后继续拖动。
  - 预期：上下左右均可到达，不误触缩小，不选中文字。
- 长按人物拖向另一人，确认或取消关系输入。
  - 预期：目标恢复颜色；仅确认后保存；取消恢复正常状态。

## 5. 服务状态

- 在不同公网IP地区启动和返回应用。
  - 预期：CN选DeepSeek，其他明确地区选GPT；检测失败提示重试。
- 正常整理、第二轮核对失败、网络断开、额度不足。
  - 预期：状态灯和详情说明实际状态；仅断网/欠费使用本地回退；已完成结果保留。
- 本轮只做本地构建，不主动调用付费API或声称实机通过。
