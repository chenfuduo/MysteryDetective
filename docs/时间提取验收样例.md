# 时间提取验收样例

目的：验收 OCR → API 提取 → 原文校验 → 待确认建议的全流程。以下是预期结果清单，**不表示已调用真实 API 验证通过**。

## 共同要求

- 仅发送 OCR 文字给 API，不发送照片；联网正常时本地扫描仅校验出处与覆盖率，不生成事件。
- 每条建议的 `quote` 必须是所属线索原文中的连续片段，保留错字、空格、换行和全角数字；点击出处应定位该片段。
- 同一时刻的不同动作可以保留；不同时间不得压成一个日期。未写年份必须保留 `--MM-DD`，不补真实年份。
- `precision` 分别使用 `date`、`hour`、`minute`。约时为 `approximate=true`，不凭空补分钟。

## 1. 用户提供的医院、城市监控原文

```text
对相关监控进行调查
医院监控显示：
◎6月16日晚10点27分，华芳进入1524病房，10点29分两开。此局白町
案发，没有其他人进入病房。
〇6月17日早晨7点09分，张怀耀从室内自行上1524病房的窗户，在
窗口停留约一分钟之后，主动跳落。
〇病房内部无监控。
城市监控显示：
◎凌展3时10分，杜光荣走出了公安局技术楼，随后他开车驶离了公安
局大院。
O凌晨3时24分，监控显示朱思俊走出了所住的公寓楼。面面显示，他
的手中拿着一个保温杯。
◎凌晨3时26分，朱思俊骑着一辆电动车驶离了小区。
◎凌股3时45分，朱思俊骑着电动车来到市郊，脱离了城市监控系统。
◎凌晨4时42分，监控显示朱思俊回到了城区。
线索卡22
```

预期至少保留以下 8 处明确时刻，均为 `minute`、`approximate=false`：

| 原文位置 | startsAt | 要求 |
| --- | --- | --- |
| 晚10点27分 | --06-16T22:27 | 保留进入事件及原文 |
| 10点29分两开 | --06-16T22:29 | 与进入分开，不因“两开”错字丢失时刻 |
| 早晨7点09分 | --06-17T07:09 | 只记录原文所述动作，不把“约一分钟”再推算成 07:10 |
| 凌展3时10分 | --06-17T03:10 | 标题变更后仍扫描，时段错字不丢掉数字 |
| 凌晨3时24分 | --06-17T03:24 | 保留后半段 |
| 凌晨3时26分 | --06-17T03:26 | 保留后半段 |
| 凌股3时45分 | --06-17T03:45 | 不要求时段词完全正确才识别钟表数字 |
| 凌晨4时42分 | --06-17T04:42 | 扫描到最后一条 |

## 2. OCR 数字与分隔形式

| OCR 原文 | startsAt | precision | approximate |
| --- | --- | --- | --- |
| ６月１６日晚１０点２７分，华芳进入病房。 | --06-16T22:27 | minute | false |
| 6 月 1 6 日晚 1 0 点 2 7 分，华芳进入病房。 | --06-16T22:27 | minute | false |
| 6月16日晚10点2（换行）7分，华芳进入病房。 | --06-16T22:27 | minute | false |
| 6月16日，22：27，华芳进入病房。 | --06-16T22:27 | minute | false |
| 6月16日，22∶27，华芳进入病房。 | --06-16T22:27 | minute | false |
| 6月16日晚十点二十七分，华芳进入病房。 | --06-16T22:27 | minute | false |
| 6月16日晚十点三刻，华芳进入病房。 | --06-16T22:45 | minute | false |
| 6月16日晚十点一刻，华芳进入病房。 | --06-16T22:15 | minute | false |
| 6月16日晚十点半，华芳进入病房。 | --06-16T22:30 | minute | false |

“（换行）”表示实际换行字符，不是原文中的括号文字。各条 quote 必须保留自身原始写法，不使用本表的标准时间替换 quote。

## 3. 精度、年份与排除项

| OCR 原文 | 预期 |
| --- | --- |
| 2025年6月16日晚10点27分进入。 | 2025-06-16T22:27，minute，false |
| 6月16日晚十点左右进入。 | --06-16T22，hour，true；不得补 :00 |
| 6月16日进入病房。 | --06-16，date，false |
| 6月16日3时通话，通话1分43秒。 | 只提取 --06-16T03，hour，false；时长不得生成事件 |
| 6月16日进入1524病房，线索卡22。 | 仅日期事件，1524、22不得识别为钟表时刻 |
| 6月16日3时10分进入，3时24分离开。 | 两条 minute 事件，不另生成重复的仅日期建议 |
| 线索甲只有6月16日，线索乙只有凌晨3时10分。 | 不得跨线索补成 --06-16T03:10 |
